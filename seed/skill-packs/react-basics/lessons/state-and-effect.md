# useState и useEffect на практике

## Идея
`useState` хранит локальное состояние компонента, а `useEffect` синхронизирует компонент с “внешним миром” (таймеры, подписки, запросы).

## Мини-конспект
- Эффекты должны быть идемпотентными: один и тот же эффект не должен ломать состояние при повторных запусках
- Всегда думай про очистку: таймеры, подписки, abort-controller
- Разделяй эффекты по причинам: один эффект — одна ответственность

## Практика
Собери поле поиска, которое не обновляет результат на каждый символ, а делает это с задержкой (debounce) и корректно чистит таймеры.
