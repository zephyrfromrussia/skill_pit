# JSX, props и композиция

## Идея
Компонент — это функция, которая из props возвращает UI. В React “переиспользование” чаще строится через композицию (вложенные компоненты, children), а не через наследование.

## Мини-конспект
- JSX — синтаксический сахар над вызовами `React.createElement`
- Props — входные данные компонента, они неизменяемые внутри компонента
- Композиция: дели UI на простые компоненты и собирай их как конструктор

## Практика
Сделай компонент кнопки с несколькими вариантами (variant) и размерами (size), который удобно использовать в приложении.
