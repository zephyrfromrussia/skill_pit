# Задание: компонент Button

Напиши React-компонент `Button`, который:
- принимает `variant`: `"primary" | "ghost" | "danger"`
- принимает `size`: `"sm" | "md" | "lg"`
- принимает стандартные props кнопки (`onClick`, `disabled`, `type`, и т.д.)
- поддерживает `children`

Требования:
- компонент типизирован (TypeScript)
- `disabled` визуально отличается и блокирует клики
- в варианте `danger` есть явный визуальный акцент

Формат ответа: вставь только код компонента (одним блоком).
