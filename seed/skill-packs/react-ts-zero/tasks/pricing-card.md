# Задание: PricingCard — адаптивная карточка

Контекст: в реальных приложениях ты постоянно собираешь “карточки” (pricing, планы, профили) из типографики, отступов, границ, состояний кнопок и адаптива. Tailwind помогает делать это быстро и предсказуемо.

## Требования
- Напиши компонент `PricingCard`.
- Props:
  - `plan: string`
  - `priceMonthly: number`
  - `features: string[]`
  - `highlight?: boolean` (по умолчанию `false`)
- Рендер:
  - Контейнер карточки (`div` или `section`) с:
    - границей, скруглением, padding
    - в светлой и тёмной теме (достаточно через `dark:*`)
  - Заголовок плана (`plan`) и цена вида: `X ₽/мес`
  - Список features через `<ul>`/`<li>` (через `map`, не забудь `key`)
  - Кнопка “Выбрать план”
    - hover-стили
    - focus-стили (ring)
  - Если `highlight === true`:
    - добавь заметный бейдж “Рекомендуем”
    - визуально подсвети карточку (например, чуть сильнее border/shadow)
- Адаптив:
  - На мобиле карточка занимает всю ширину контейнера.
  - На `sm` и выше — ограничь ширину и/или сделай более “плотную” раскладку (хотя бы один `sm:*` класс).

## Ограничения
- Только Tailwind в `className` (не пиши отдельный CSS).
- Не используй `any`.
- Не используй внешние библиотеки.

## Формат ответа
Вставь только код компонента (одним блоком).

## Самопроверка
- Mobile-first: базовые классы работают на мобиле, `sm:*` улучшает на больших экранах.
- Есть hover и focus (ring) для кнопки.
- Список features рендерится корректно со стабильными `key`.
- Нет горизонтального скролла (не используй фиксированные ширины типа `w-[900px]`).
