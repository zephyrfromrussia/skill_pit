# Задание: AnimatedToast — enter/exit анимация

Контекст: в приложениях часто нужно показывать временные уведомления (toast). Здесь важно: управление состоянием, аккуратная анимация появления/исчезновения и UI без переполнений на мобиле.

## Требования
- Напиши компонент `AnimatedToast`.
- Props:
  - `message: string`
- Поведение:
  - Внутри компонента есть state `open: boolean` (по умолчанию `false`).
  - Кнопка “Показать уведомление” открывает toast.
  - Внутри toast есть кнопка “Закрыть”, которая закрывает toast.
  - Toast должен исчезать с `exit` анимацией (не мгновенно).
- Анимация (Framer Motion):
  - Используй `AnimatePresence`.
  - Toast — это `motion.div` с:
    - `initial` (opacity 0, y 12)
    - `animate` (opacity 1, y 0)
    - `exit` (opacity 0, y 12)
    - `transition` с длительностью 0.15–0.25
- UI (Tailwind):
  - Toast должен быть читаемым (фон, border, padding).
  - Ширина должна адаптироваться (например, `max-w-md w-full`), без горизонтального скролла.

## Ограничения
- Не используй внешние библиотеки кроме `framer-motion`.
- Не используй `any`.

## Формат ответа
Вставь только код компонента (одним блоком).

## Самопроверка
- `exit` реально проигрывается (есть `AnimatePresence`).
- Кнопки работают, состояние не “залипает”.
- На мобиле toast не вылезает за край (нет фиксированных ширин).
