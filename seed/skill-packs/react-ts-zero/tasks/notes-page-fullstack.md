# Задание: NotesPage — форма + список + анимация

Контекст: у тебя есть Notes API и типизированный клиент `NotesApi`. Теперь нужно собрать страницу, которая честно проходит через состояния загрузки/ошибки и даёт понятный UX на мобиле. Финальный штрих — анимация списка, чтобы добавление/удаление было визуально “считываемым”.

## Требования
Напиши компонент `NotesPage` (одним файлом). Он должен:

1) Данные и состояния
- Держать `items: NoteDto[]`
- Держать `text: string` для инпута
- Держать `status: 'idle' | 'loading' | 'error'`
- Держать `error: string | null`

2) Загрузка при монтировании
- В `useEffect`:
  - создать `const controller = new AbortController()`
  - вызвать `getNotes(controller.signal)`
  - в cleanup вызвать `controller.abort()`
- Ошибку `AbortError` не показывать пользователю.
- Для остальных ошибок показать текст в UI.

3) Создание заметки
- Кнопка “Добавить”:
  - disabled, если `text.trim()` пустой или идёт загрузка
  - по клику вызывает `createNote({ text: text.trim() })`
  - после успеха добавляет новую заметку в начало списка
  - очищает инпут

4) Удаление заметки
- На каждой заметке есть кнопка “Удалить”:
  - вызывает `deleteNote(id)`
  - после успеха удаляет элемент из `items`

5) Верстка (Tailwind)
- Контейнер страницы: `max-w-2xl` и центрирование (чтобы на desktop не было “растянутой простыни”).
- Инпут и кнопка адаптивны: на мобиле колонкой, на `sm:` в строку.
- Карточка заметки не вызывает горизонтальный скролл:
  - используй `min-w-0` и `break-words` для текста
  - кнопка удаления не должна “выталкивать” текст

6) Анимация (Framer Motion)
- Список заметок — `AnimatePresence initial={false}`
- Элемент списка — `motion.li` с:
  - `key={note.id}`
  - `layout`
  - `initial/animate/exit` (opacity + небольшой y)
  - короткий `transition` (около 0.15–0.25s)

## Ограничения
- Никаких библиотек для data fetching (React Query и т.п.) — только `fetch` через `NotesApi`.
- Не используй `key={index}`.
- Не используй `any`.

## Формат ответа
Вставь код файла `NotesPage.tsx`:

```tsx
// NotesPage.tsx
...
```

## Самопроверка
- При размонтировании страницы запрос не пытается обновить state.
- Ошибка сети/500 отображается, AbortError — нет.
- На узком экране нет горизонтального скролла даже при длинном тексте.
- Добавление/удаление заметки видно глазами (enter/exit) и список перестраивается плавно (layout).
