# Задание: TodoList — добавить/удалить

Контекст: списки — одна из самых частых задач в UI. Ты потренируешь `map`, `key`, работу с массивом в state и контролируемым инпутом.

## Требования
- Напиши компонент `TodoList`.
- Внутри компонента определи тип:
  - `type TodoItem = { id: string; text: string; done: boolean }`
- State:
  - `items: TodoItem[]`
  - `draft: string` (текст нового пункта)
- Поведение:
  - Инпут контролируемый для `draft`.
  - Кнопка “Добавить”:
    - создаёт новый элемент `{ id: crypto.randomUUID(), text: draft.trim(), done: false }`
    - добавляет его в конец списка
    - очищает `draft`
    - кнопка disabled, если `draft.trim()` пустой
  - Кнопка “Готово/Вернуть” у каждого пункта — переключает `done`.
  - Кнопка “Удалить” — удаляет пункт по `id`.
- Рендер:
  - Список `<ul>`, элементы `<li>`.
  - Каждый `<li>` обязан иметь `key={item.id}`.
  - Для выполненных пунктов (`done === true`) добавь явный маркер в тексте: например, префикс `✓ `.

## Ограничения
- Не мутируй массив в state (никаких `push`, `splice` по месту).
- Не используй `index` как key.
- Не используй внешние библиотеки.

## Формат ответа
Вставь только код компонента (одним блоком).

## Самопроверка
- Добавление/удаление/переключение работает без мутаций.
- key стабильный и основан на id.
- Типы `TodoItem`, state и обработчиков корректны.
