# Задание: Counter — состояние и обновления

Контекст: счётчик — минимальный пример state. Здесь важно обновлять state корректно и типизировать API.

## Требования
- Напиши компонент `Counter`.
- Props:
  - `initial?: number` (по умолчанию `0`)
  - `min?: number` (по умолчанию `0`)
  - `max?: number` (по умолчанию `10`)
  - `onChange?: (value: number) => void`
- Поведение:
  - В state хранится текущее значение `count`.
  - При клике “+” увеличивай `count` на 1, но не выше `max`.
  - При клике “−” уменьшаяй `count` на 1, но не ниже `min`.
  - Кнопки должны быть `disabled`, если достигнута граница (на `min` нельзя “−”, на `max` нельзя “+”).
  - Если передан `onChange`, вызывай его с новым значением после изменения.
- UI:
  - Покажи число крупно (например, в `<div>`).
  - Кнопки с текстом “−” и “+”.

## Ограничения
- Используй функциональную форму обновления state: `setCount((c) => ...)`.
- Не используй `any`.
- Не используй внешние библиотеки.

## Формат ответа
Вставь только код компонента (одним блоком).

## Самопроверка
- Границы `min/max` соблюдаются и через UI, и в логике.
- `onChange` вызывается только при реальном изменении.
- Типы props и обработчиков корректны.
