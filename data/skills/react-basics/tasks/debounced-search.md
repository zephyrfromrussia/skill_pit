# Задание: Debounced Search (без библиотек)

Напиши React-компонент `DebouncedSearch`, который:
- имеет текстовое поле ввода
- показывает “результаты” как список строк (можно использовать мок-данные внутри компонента)
- обновляет фильтрацию не на каждый символ, а с задержкой 300–500мс (debounce)
- корректно очищает таймер при размонтировании и при вводе нового значения

Требования:
- чистый TypeScript
- без сторонних библиотек debounce
- UX: покажи состояние “ничего не найдено”, когда результатов нет

Формат ответа: вставь только код компонента (одним блоком).
