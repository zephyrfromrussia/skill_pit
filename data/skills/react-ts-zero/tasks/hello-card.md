# Задание: HelloCard — первый компонент

Контекст: ты пишешь первый компонент на React + TypeScript. Цель — научиться делать простой UI, получать данные через props и рендерить их через JSX.

## Требования
- Напиши компонент `HelloCard`.
- Компонент принимает props:
  - `name: string`
  - `topic: string` (например, `"React"`)
  - `completedLessons: number`
  - `mode?: "friendly" | "strict"` (по умолчанию `"friendly"`)
- Рендер:
  - Заголовок: `Привет, {name}!`
  - Подзаголовок: `Тема: {topic}`
  - Строка прогресса:
    - если `completedLessons === 0`: `Ты ещё не проходил уроки — начни с первого.`
    - иначе: `Уроков пройдено: {completedLessons}`
  - Режим:
    - `"friendly"` → бейдж `Режим: дружелюбный`
    - `"strict"` → бейдж `Режим: строгий`

## Ограничения
- Только функциональный компонент (без классов).
- Не используй `any`.
- Не используй внешние библиотеки.

## Формат ответа
Вставь только код компонента (одним блоком).

## Самопроверка
- Компонент типизирован: props имеют явный тип.
- Есть дефолт для `mode`.
- Условия для текста прогресса работают корректно.
- JSX читается (нет “каши” из тернарников на 5 строк).
