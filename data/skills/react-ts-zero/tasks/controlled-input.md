# Задание: ControlledInput — форма без сюрпризов

Контекст: контролируемый инпут — это когда `value` хранится в state, а изменения идут через `onChange`. Так приложение всегда “знает”, что сейчас в поле.

## Требования
- Напиши компонент `ControlledInput`.
- Props:
  - `label: string`
  - `maxLength: number`
- Поведение:
  - В state хранится строка `value`.
  - `input` контролируемый: `value={value}`.
  - `onChange` типизирован (не `any`), и обновляет state через `e.target.value`.
  - Если введённый текст длиннее `maxLength`, не давай ему расти: обрезай до `maxLength`.
- UI:
  - Отрисуй `<label>` и `<input>` (можно без `id`, но лучше с `id` и `htmlFor`).
  - Под полем покажи: `Символов: {value.length}/{maxLength}`.
  - Если `value.length === 0`, покажи подсказку: `Введи текст выше.`

## Ограничения
- Только функциональный компонент.
- Не используй внешние библиотеки.

## Формат ответа
Вставь только код компонента (одним блоком).

## Самопроверка
- Инпут остаётся контролируемым (нет `undefined` в value).
- Тип события в `onChange` корректный.
- Лимит `maxLength` реально работает.
