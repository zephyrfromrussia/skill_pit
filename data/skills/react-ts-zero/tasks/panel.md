# Задание: Panel — обёртка с children

Контекст: в React часто делают компоненты-обёртки (карточки/панели), которые принимают `children`. Твоя задача — спроектировать удобный API и типы.

## Требования
- Напиши компонент `Panel`.
- Props:
  - `title?: string`
  - `children: React.ReactNode`
  - `footer?: React.ReactNode`
  - `tone?: "default" | "danger"` (по умолчанию `"default"`)
- Рендер:
  - Внешний контейнер `<section>`.
  - Если `title` задан:
    - отрисуй заголовок `<h2>` внутри `<header>`.
  - Основной контент (`children`) рендери внутри `<div>`.
  - Если `footer` задан — отрисуй его внутри `<footer>`.
  - Если `tone === "danger"` — добавь заметный текстовый маркер рядом с заголовком: `⚠️` (можно просто строкой).

## Ограничения
- Только функциональный компонент.
- Не используй `any`.
- Не используй внешние библиотеки.

## Формат ответа
Вставь только код компонента (одним блоком).

## Самопроверка
- `children` типизирован как `React.ReactNode`.
- `title` и `footer` необязательные и корректно обрабатываются.
- Дефолт `tone` работает.
- Семантика правильная: section/header/h2/footer используются по назначению.
