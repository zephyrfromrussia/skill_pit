# Компонент и JSX: первый шаг

## Идея
В React UI строится из компонентов. Компонент — это функция, которая возвращает разметку (JSX). JSX похож на HTML, но это синтаксис внутри JavaScript/TypeScript, поэтому в нём действуют правила языка (например, выражения пишутся в фигурных скобках).
TypeScript добавляет типы: он помогает заранее увидеть ошибки в props и в JSX-атрибутах.

## Мини-конспект
- Компонент — обычная функция, имя компонента начинается с заглавной буквы.
- Компонент возвращает JSX (разметку), обычно через `return (...)`.
- В JSX можно вставлять выражения: `{2 + 2}`, `{name}`, `{isOk ? 'OK' : 'Нет'}`.
- В JSX атрибуты похожи на HTML, но некоторые называются иначе: `className`, `htmlFor`.
- В `.tsx` нельзя использовать “угловой” type assertion (`<Foo>bar`), используй `as`.
- Props — единственный аргумент компонента; чаще сразу деструктурируют `({ title, subtitle })`.

## Типовые ошибки
- Компонент назван с маленькой буквы → React считает это HTML-тегом и ломает рендер.
- `return` на новой строке без скобок → из-за автоматической точки с запятой вернётся `undefined`.
- Пытаются писать `if` внутри JSX без `{}` и тернарного оператора.
- Путают `class` и `className`.
- Путают “значение” и “вызов” обработчика: `onClick={handle}` (правильно) vs `onClick={handle()}` (не то).

## Практика
- Напишешь первый компонент на TypeScript.
- Опишешь тип props.
- Соберёшь простой UI из заголовка, текста и “бейджа”.
